Положите сюда 3 видео для холодного старта ролика.

Имена файлов (по ключевым словам в названии):
- Dark Souls:  souls / dark / ds     (например: dark-souls.mp4)
- Mario Kart:  kart / mario / mk     (например: mario-kart.mp4)
- JS-анимация: anim / js             (например: js-anim.mp4)

Если названия без ключевых слов — порядок по алфавиту:
1-е → Dark Souls, 2-е → Mario Kart, 3-е → JS-анимация.

Поддерживаются: .mp4 .mov .webm .mkv .avi .m4v
После добавления файлов: npm run render
(скрипт scripts/check-montage.js подхватит их автоматически)
